# 🍽️ Restaurant Website

A modern and responsive restaurant website designed to showcase food items, special dishes, and restaurant services with an attractive user interface and smooth user experience.

---

## 🚀 Features

- 🍕 Responsive Restaurant Landing Page
- 📋 Food Menu Section
- 🖼️ Attractive UI Design
- 📱 Fully Mobile Responsive
- ⚡ Smooth Animations & Scrolling
- 📞 Contact Section
- 🌙 Clean and Modern Layout

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

---

## 📂 Project Structure

```bash
Restaurant/
│── index.html
│── style.css
│── script.js
│── assets/
│── images/
```

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Neej03/Restaurant.git
```

Go to the project directory:

```bash
cd Restaurant
```

Open `index.html` in your browser.
